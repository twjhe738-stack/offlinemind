# Changelog

## 0.1.0 - foundation

- Added a minimal Kotlin/Compose Android application shell with explicit no-model and no-inference messaging.
- Added a tested generation-state transition model.
- Kept the app manifest free of permissions and disabled backup.
- Added CI build/test/lint and no-`INTERNET` permission checks.
- Documented architecture, toolchain evidence, limitations, privacy, testing, and model/licence status.

This is not a release candidate: model import, native inference, chat persistence, APK build, and physical-device tests remain incomplete or unverified.
